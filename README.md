# Расширенная рабочая область ROS2

Этот проект предназначен для хранения универсальной рабочей области для быстрого развертывания всех необходимых
инструментов, программ, пакетов ROS2 для работы с мобильными роботами и другими РТК.

Основной перечень инструментов включает в себя пакеты, которые устанавливаются в корневой каталог ROS2: 
1) Фреймворк ROS2 и его утилиты;
2) Крупные стеки (nav2, rtabmap);
3) Программа симуляции роботов gz sim;

Дополнительные пакеты, которые устанавливаются в локальную рабочую области:
1) Realsense ROS2 SDK;
2) Slamtech ROS2 SDK;
